SOP Robot Mata OLED
ESP32-C3 + Sensor Sentuh

Prosedur standar pembuatan, pengoperasian, dan perawatan project ekspresi mata OLED dengan 13 ekspresi, tampilan nama, dan 5 mini game.

ESP32-C3OLED SSD1306 128x64TTP22313 ekspresi5 game

01Tujuan & Ruang Lingkup

SOP ini memastikan project dirakit, diunggah, dan dioperasikan dengan cara yang sama setiap kali, sehingga hasilnya konsisten dan mudah diperbaiki bila ada masalah.

  • Fungsi utama: menampilkan ekspresi mata lucu di OLED yang berganti otomatis atau lewat sentuhan.
  • Fitur tambahan: tampilan nama, kredit, quote, dan 5 mini game (cacing, menara blok, dino, Tetris, Flappy Bird).
  • Kendali: satu sensor sentuh dan Serial Monitor.

HWHardware Detail

Spesifikasi tiap komponen yang dipakai di project ini beserta diagram sambungannya.

🧠 ESP32-C3 Super Mini

  • Prosesor: RISC-V 32-bit, hingga 160 MHz
  • Konektivitas: WiFi 2,4 GHz + Bluetooth LE 5
  • Memori: flash 4 MB
  • Port: USB-C (upload & Serial)
  • Logika: 3,3 V
  • Peran: otak yang menggambar mata, game, dan membaca sentuhan

📺 OLED SSD1306

  • Ukuran: 0,96 inci, monokrom
  • Resolusi: 128 x 64 piksel
  • Antarmuka: I2C, 4 pin (VDD, GND, SCK, SDA)
  • Alamat I2C: 0x3C (kadang 0x3D)
  • Tegangan: pakai 3V3
  • Peran: layar ekspresi mata dan game

👆 Sensor Sentuh TTP223

  • Jenis: sensor sentuh kapasitif
  • Pin: VCC, GND, OUT
  • Tegangan: sekitar 2 – 5,5 V (pakai 3V3)
  • Keluaran: HIGH saat disentuh (mode bawaan)
  • Mode: bisa diubah lewat jumper/pad di modul
  • Peran: satu-satunya tombol kendali

🔌 Kabel & Pendukung

  • Kabel jumper: 7 buah (4 OLED + 3 sensor)
  • Kabel USB-C: harus kabel data, bukan kabel charge saja
  • Opsional: header solder agar sambungan tidak lepas
  • Opsional: breadboard untuk uji coba

Diagram Sambungan

Warna kabel: merah = 3V3, abu-abu = GND, biru = SDA, kuning = SCL, hijau = sinyal sensor sentuh.

04Persiapan & Upload Kode

  1. Pasang Arduino IDE dan board package esp32.
  2. Install library Adafruit SSD1306 dan Adafruit GFX lewat Library Manager.
  3. Pilih Tools → Board → ESP32C3 Dev Module.
  4. Aktifkan Tools → USB CDC On Boot → Enabled.
  5. Pilih port yang benar, lalu klik Upload.
  6. Buka Serial Monitor di 115200 baud untuk memastikan program berjalan.
Catatan kode: jangan memakai nama variabel RX atau LX untuk posisi mata. Di ESP32-C3, RX sudah dipakai board. Gunakan EYE_L dan EYE_R.

06Panduan Mini Game

Cacing (tap 5x)
  • Tap = belok kanan, tahan ±0,4 detik = belok kiri.
  • Makan kotak berkedip agar makin panjang dan cepat.
  • Kena badan sendiri = game over. Tembok bisa ditembus.
Menara blok (tap 6x)
  • Tap = jatuhkan blok yang bergeser.
  • Bagian yang menjorok terpotong. Selisih 2 piksel atau kurang = PERFECT.
  • Meleset total = game over.
Dino (tap 7x)
  • Tap = loncat melewati kaktus (hanya saat di tanah).
  • Makin jauh berlari, makin cepat.
Tetris (tap 8x)
  • Tap = putar. Tahan = geser (bolak-balik otomatis). Tap 2x cepat = jatuhkan langsung.
  • Titik kecil menunjukkan bayangan tempat mendarat. Tiap 10 baris naik level.
  • Saat bermain, tahan 3 detik untuk keluar.
Flappy Bird (tap 9x)
  • Tap = burung loncat. Hindari pipa.
  • Skor naik tiap melewati pipa.
Aturan umum: saat game over, tap = main lagi dan tahan 1,5 detik = keluar ke mata. Skor terbaik hilang saat ESP32 di-restart.

08Troubleshooting

Layar OLED kosong
  • Cek kabel SDA (GPIO 8) dan SCL (GPIO 9) tidak tertukar.
  • Ganti OLED_ADDR dari 0x3C ke 0x3D.
  • Pastikan daya 3V3 dan GND terpasang.
Error “conflicting declaration RX”
Ganti semua RX menjadi EYE_R dan LX menjadi EYE_L (Ctrl + H, centang Match case).
Serial Monitor kosong
Aktifkan USB CDC On Boot, set baud 115200, lalu tekan reset.
Sensor sentuh tidak merespons / terbalik
  • Cek OUT ke GPIO 4 dan daya 3V3.
  • Jika logikanya terbalik, ubah == HIGH menjadi == LOW pada pembacaan TOUCH_PIN.
Tap berkali-kali sulit terbaca
Perbesar DOUBLE_MS (misalnya 350 → 450) agar jeda antar tap lebih longgar.
Upload gagal
Pakai kabel USB data (bukan kabel charge saja). Tahan tombol BOOT, tekan RESET, lepas BOOT, lalu upload ulang.
Flappy Bird: celah pipa selalu sama / burung langsung jatuh
Ganti rentang acak menjadi random(8, F_GROUND - 8 - F_PIPE_GAP + 1), tambahkan status “melayang” sampai tap pertama, dan kurangi F_JUMP ke sekitar -180.

10Perawatan & Keselamatan

  • Jangan menyambung ke 5V. OLED dan sensor memakai 3V3.
  • Lepas USB saat mengubah wiring.
  • Simpan kode lama (backup) sebelum mengubah atau menambah fitur.
  • Bersihkan layar OLED dengan kain kering lembut.
  • Jika perangkat panas atau berbau, cabut daya dan periksa kabel yang korslet.
